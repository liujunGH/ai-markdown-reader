# v2.1.1 — macOS 原生架构打包修复

v2.1.1 修复 Apple Silicon 版本误带 Intel 原生组件、触发 macOS 兼容性提醒的问题。

## 修复

- Apple Silicon 安装包只保留 `darwin-arm64` 的 better-sqlite3 原生模块。
- Intel 安装包只保留 `darwin-x64` 的 better-sqlite3 原生模块。
- Windows 与 Linux 安装包也会按各自的平台和目标架构裁剪预编译原生模块。
- 排除仅供 node-gyp 编译使用的 Python、测试扩展和其他构建期产物。
- 关闭 electron-builder 对原生依赖目录的整包自动解包，只解包运行时需要的 `.node` 文件。
- 新增打包后架构校验；目标模块缺失或存在其他平台、架构的模块时，构建会直接失败。

## 影响

v2.1.0 及更早的 Apple Silicon 安装包主程序本身是 arm64，但依赖目录中可能包含带 x86_64 切片的编译工具或预编译模块，因此 macOS 会提示该 App 包含未来不再兼容的 Intel 组件。v2.1.1 已移除这些非运行时文件，SQLite 和阅读数据功能不受影响。

## 验证

- arm64 App 全包 Mach-O 扫描：0 个 x86_64 文件。
- arm64 App 仅包含 `darwin-arm64.node`；x64 App 仅包含 `darwin-x64.node`。
- arm64 与 x64 实包均成功启动、加载页面、创建 SQLite 数据库并完成迁移。
- macOS App 深度代码签名结构验证通过。
- TypeScript 检查和 259 个单元测试通过。

## 安装建议

Apple Silicon 用户请选择文件名带 `arm64` 的 DMG；Intel Mac 用户请选择 `x64`。从旧版本升级到 v2.1.1 后，macOS 不应再检测到 Markdown Reader 包内的 Intel 兼容组件。
