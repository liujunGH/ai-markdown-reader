# v2.1.0 — 阅读体验、长文性能与更新闭环

v2.1.0 聚焦三个目标：长文档更快呈现且内存有界，阅读交互更加可靠，软件更新从提示走到可安装的完整闭环。

## 长文档性能

- **首段优先显示**：Markdown 按约 64KB 安全边界分段，首段解析完成即可阅读，后续目录与块索引在后台继续补齐。
- **按需 HTML**：块模型只保存原始 Markdown 和布局元数据；仅可见区前后预取窗口交给 Worker 生成 HTML。
- **有界缓存**：HTML 使用 160 块 LRU，同一文档的多视图共享解析结果，避免长文档与分屏场景重复持有整篇渲染结果。
- **搜索与统计降阻塞**：百万字符以上正文搜索迁移到独立 Worker，状态栏统计改为单次低分配扫描。
- **尾部阅读优化**：完整索引结束后预热尾部 20 块，拖动滚动条到底和恢复尾部进度更快；增量索引期间保持尾部锚定。
- **动态高度可靠性**：Mermaid 等异步内容改变块高度后重新测量可见块，避免覆盖后续正文。

## 阅读体验修复

- 首次引导从第 1 步开始，跳过或完成后立即关闭。
- 内置示例在会话恢复时重新注入正文，不再恢复为空标签。
- 搜索高亮不改写 Mermaid、KaTeX 和代码 DOM，关闭搜索会清理残留高亮。
- 切换主题后自动重新渲染 Mermaid。
- 专注模式隐藏工具栏、标签栏、侧栏、目录和状态栏，并保留退出入口。
- 源码视图完整覆盖阅读区，不再裁掉首行。
- 未打开工作区时，全局搜索提供明确的“打开文件夹”入口。
- 命令面板在 macOS 使用 `⌘` / `⇧` 等原生符号，并移除冲突快捷键提示。

## 软件更新

- 安装包启动后静默检查更新；无更新或后台检查失败不会打断阅读。
- 可从“帮助 → 检查更新…”或命令面板主动检查。
- 发现新版本时显示版本号和发行说明，由用户确认后再下载。
- 支持下载百分比和字节进度、失败重试、下载完成后“重启并安装”。
- 多窗口共享并可主动查询当前更新状态，避免新窗口错过早先事件。
- 开发模式不连接发布源，并显示明确说明。

## 发行维护

- macOS 同时生成 DMG 和自动更新所需的 ZIP、blockmap、`latest-mac.yml`。
- GitHub Actions 按 Windows、macOS、Linux 三平台构建并发布安装包与更新清单。
- 三个平台先上传独立 Actions artifact，全部成功后再由单独作业统一发布 Release，避免更新清单与 blockmap 的并发上传竞争。
- 运行时与工具链升级到 Electron 43、better-sqlite3 13、electron-builder 26、Vite 8 和 Vitest 4；DOMPurify、markdown-it、Mermaid、electron-updater 同步到安全修复版本。
- Node.js 最低版本调整为 22.12，生产与完整 `npm audit` 均为 0 项已知漏洞。
- 更新 README、CHANGELOG、安全支持版本、E2E 指南和发布流程。

### 当前机器性能实测

| 场景 | 指标 | v2.1.0 |
|---|---|---:|
| 5MB 单文档 | 正文首屏 | 619.6ms |
| 5MB 单文档 | 首次搜索高亮 | 73.8ms |
| 5MB 单文档 | 尾部按需渲染 | 39.5ms |
| 12×5MB 会话 | 当前文档首屏 | 603.7ms |
| 12×5MB 会话 | 未加载标签切换 | 143.7ms |
| 12×5MB 会话 | 即时 / 稳定工作集 | 678.0 / 794.5MB |

与 2026-05-17 的旧架构同机基线相比，5MB 文档首屏、搜索高亮和尾部渲染分别改善约 63%、99% 和 89%；大会话当前文档与标签切换分别改善约 57% 和 77%。这是单次本机结果，用于版本回归参考，不作为跨机器绝对承诺。

## macOS 签名说明

本地自测包使用 ad-hoc 签名。面向用户的自动替换安装需要在 GitHub Actions 配置 Developer ID 证书并完成公证，否则 macOS 安全策略可能阻止自动安装。
