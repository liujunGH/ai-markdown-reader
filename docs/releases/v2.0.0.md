# v2.0.0 — 底层架构重写

## 概述

v2.0.0 是一次完整的底层架构重写，解决了 v1 的三大性能问题：渲染卡顿（整篇 DOM + 8 轮补丁）、内存增长（虚拟化不回收 + content 在状态树）、状态重渲染（全量订阅）。

## 架构变更

### 渲染层
- **token pipeline + 块模型**：markdown-it 解析 → 按语义边界切块（标题/段落/代码/表格/列表/引用/公式），绝不在表格/代码块中间切断
- **TanStack Virtual 虚拟列表**：按可见区间映射块到 DOM，滚出视口自动卸载（根治旧 VirtualMarkdown visibleIds 只增不减）
- **块级 DOM 增强**：8 项增强（链接/表格/代码/task list/KaTeX/wiki/图片/Mermaid）作用于单个块，非整篇 querySelectorAll
- **heading id 注入**：标题 id 在块 HTML 生成时注入，供大纲/锚点/scrollspy

### 资源层
- **DocumentCache LRU**：content 移出 Zustand 状态树，进 LRU 缓存（容量 4），超出淘汰

### 主进程
- **IPC 按领域拆分**：1398 行 main.ts → fileHandler/dialogHandler/windowHandler/storageHandler/dbHandler
- **SQLite 层**：better-sqlite3 + FTS5 trigram（中文全文检索），取代 IndexedDB

### 状态层
- **selector 友好**：组件用 `useStore(s => s.field)` 单字段订阅，uiStore 18 面板用 Record
- **readingStore**：从 App.tsx 抽出 15 个阅读状态 + 派生 selector

## 功能（1:1 迁移，无丢失）
文件打开/标签管理/渲染（Mermaid/KaTeX/代码高亮/表格/task list/图片）、搜索（文内/跨标签/命令面板/快速跳转）、目录大纲、工作区（文件树/最近/欢迎）、主题切换、导出（HTML/PDF/打印/复制）、全局搜索（FTS5）、阅读工具（18 功能区）
