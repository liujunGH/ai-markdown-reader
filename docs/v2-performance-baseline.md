# v2.1 性能验证基线

本文记录同一台机器上的发布前单次实测，用于后续版本回归。数值会受到系统负载、Electron 缓存和硬件状态影响，不应视为跨机器 SLA。

## 测试方法

- 旧基线：2026-05-17，整篇 HTML 渲染架构。
- 当前基线：2026-08-03，v2.1.0 分段解析与按需 HTML 架构。
- 单文档：`npm run perf:document -- --mb=5`。
- 大会话：`npm run perf:startup`，恢复 12 个 5MB 标签，共 60MB。
- 两组脚本都启动实际 Electron 主进程和生产构建，不使用纯浏览器模拟。

| 完整块索引 | 未记录 | 1762.1ms | 新增后台指标 |
| 首次搜索高亮 | 5552.9ms | 73.8ms | -98.7% |
| 滚动到底部渲染 | 358.8ms | 39.5ms | -89.0% |
| 即时工作集 | 936.7MB | 803.3MB | -14.2% |
| 稳定工作集 | 未记录 | 803.6MB | 新增稳定态指标 |

首屏在完整索引之前约 1.14 秒可用，说明“首段先显示、后台补索引”按预期工作。搜索和尾部渲染不再等待整篇 HTML 常驻主线程。

| 指标 | 旧基线 | v2.1.0 | 变化 |
|---|---:|---:|---:|
| 根节点可见 | 358.9ms | 420.8ms | +61.9ms |
| 标签恢复 | 1165.1ms | 424.1ms | -63.6% |
| 当前文档首屏 | 1399.6ms | 603.7ms | -56.9% |
| 未加载标签切换 | 638.1ms | 143.7ms | -77.5% |
| 即时工作集 | 1168.8MB | 678.0MB | -42.0% |
| 稳定工作集 | 未记录 | 794.5MB | 新增稳定态指标 |

大数据会话的根节点可见比旧基线慢约 62ms，但标签恢复、当前文档可读、标签切换和内存均明显改善。空会话根节点可见为 384.2ms，和旧基线 379.4ms 基本一致，因此代价主要出现在大会话初始化协调，而不是基础壳启动。

## 改善机制

- Markdown 按约 64KB 安全边界分段，首段完成即可呈现。
- 块模型只保存源码、元数据与高度估算，不提前保存整篇 HTML。
- 可见区及前后预取窗口交给独立 Worker 渲染，HTML LRU 上限为 160 块。
- 同文档多视图共享解析 Promise 与块模型；单栏只保留当前解析结果。
- 百万字符正文搜索由独立 Worker 执行，状态栏统计使用单次低分配扫描。
- 完整索引完成后只预热尾部 20 块，覆盖滚动到底和进度恢复。

## 发布门禁

- 259 项单元测试通过。
- 15/15 渲染正确性检查通过。
- 8/8 Electron E2E 通过。
- TypeScript、Electron 主进程编译和 Vite 生产构建通过。

后续版本应至少复跑上述两个性能脚本；如果同机同负载下核心指标连续回退超过 20%，需要在发行说明中解释原因或阻止发布。
